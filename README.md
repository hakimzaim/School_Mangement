# School Management App (Flutter)

Application Flutter pour la gestion de scolarité et la relation entre les parents et l'école.

## Rôles couverts
- **Admin** : inscriptions, pilotage académique, communication globale.
- **Enseignant** : notes, absences, messagerie parents.
- **Parent** : suivi de scolarité, alertes absences, relation avec l'école.

## Lancer le projet
```bash
flutter pub get
flutter run
```

## Tester
```bash
flutter test
```
